## 3. 失败仲裁，只发送一次

订单0是Paid，没有争议。尝试卖家胜诉应被合约拒绝。这一步是课程要求的失败案例，会向测试网广播交易。

```bash
date -Is
curl --silent --show-error --max-time 120 \
  --request POST \
  --dump-header evidence/potos/arbitration-member3/01-failed-resolve.headers.txt \
  --output evidence/potos/arbitration-member3/01-failed-resolve.json \
  --write-out 'HTTP %{http_code}\n' \
  'http://127.0.0.1:8080/api/escrow/orders/0/resolve?sellerWins=true'

```

正常预期：HTTP `409`；message包含交易失败/回滚信息；若已入块，响应应带transactionHash、blockNumber、`status: 0x0`、gasUsed。
