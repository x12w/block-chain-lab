## 你现在做：买家创建并付款

在 Remix 编译项目中相同的 Escrow.sol 和 WQLToken.sol，使用连接个人钱包的环境，
确认钱包网络和地址。分别通过 At Address 加载上面的新 Escrow、原 WQLToken。
这一步是加载已有合约，不要点击 Deploy 另建合约。

操作前即时计算 30 分钟后的 deadline（Unix 秒）：

```bash
python3 -c 'import time; print(int(time.time()) + 1800)'
```

在 Escrow 上依次调用两次 createOrder，输入 seller、token、amount、deadline、description。
两次的前三项相同，description 可分别填 `route A normal order` 和 `route A disputed order`。
当前新合约没有订单，预计产生 0、1；以实际 OrderCreated 事件中的 ID 为准。

然后在 WQLToken 上调用 approve：

```text
spender = 0xd7320d80b687766bA73997B97dAE61Ff1f9ed737
value   = 60000000000000000000
```

回到 Escrow，依次 deposit(0)、deposit(1)，等待两笔确认，并核对都为 Paid。
保留两笔创建、一次授权、两笔付款的 5 个交易哈希和截图。**第一笔暂时不要 confirm。**

买家付款、卖家争议完成后，把实际订单 ID 和交易哈希汇总。
